# 특별한 이차원 배열 2

## 문제 설명
n × n 크기의 이차원 배열 `arr`이 매개변수로 주어질 때, `arr`이 다음을 만족하면 1을 아니라면 0을 return 하는 solution 함수를 작성해 주세요.

- 0 ≤ i, j < n인 정수 i, j에 대하여 `arr[i][j]` = `arr[j][i]`

## 제한사항
- 1 ≤ `arr`의 길이 = `arr`의 원소의 길이 ≤ 100
- 1 ≤ `arr`의 원소의 원소 ≤ 1,000
- 모든 `arr`의 원소의 길이는 같습니다.

## 입출력 예
| arr | result |
| :-- | :-- |
| [[5, 192, 33], [192, 72, 95], [33, 95, 999]] | 1 |
| [[19, 498, 258, 587], [63, 93, 7, 754], [258, 7, 1000, 723], [587, 754, 723, 81]] | 0 |

## 입출력 예 설명
입출력 예 #1
- 예제 1번에서 문제의 조건이 잘 보이도록 표를 만들면 다음과 같습니다.

| i | j | arr[i][j] | arr[j][i] |
| :-- | :-- | :-- | :-- |
| 0 | 0 | 5 | 5 |
| 0 | 1 | 192 | 192 |
| 0 | 2 | 33 | 33 |
| 1 | 0 | 192 | 192 |
| 1 | 1 | 72 | 72 |
| 1 | 2 | 95 | 95 |
| 2 | 0 | 33 | 33 |
| 2 | 1 | 95 | 95 |
| 2 | 2 | 999 | 999 |

```
조건을 만족하므로 1을 return 합니다.
```

입출력 예 #2
- 예제 2번의 `arr`에서 `arr[0][1]` = 498 ≠ 63 = `arr[1][0]`이므로 조건을 만족하지 않습니다. 따라서 0을 return 합니다.

## 배운점
- `enumerated()`를 사용하지 않고 `range`로만 이차원 배열의 인덱스 검색하는것이 가독성 측면과 성능면에서 더 좋은 선택지임을 알게 되었다.

- 대칭 행렬의 고유성질을 활용하여 전체 공가능 전부 순회할 필요가 없다는 것을 알게 되어 내부 루프의 범위를 `(i + 1)..<arr.count`로 설정하여 좌상단부터 우하단의 대각선을 제외한 우측 상단의 삼각형 영역만을 순회하도록 함으로 중복 조회를 막고 연산의 속도를 2배 단축 할수 있다는것을 알게되었다.

- 루프내에서 모든 조건에 대한 루프를 돌리는 것보다 단 한번이라도 조건에 충족한다면 그 즉시 값을 리턴하며 루프를 종료하도록 하는것이 성능과 안정성에서 좋다는것을 다시 한번 인지할수 있었다.

- `for`루프에서 `where`를 사용할 수 있다는것을 알게 되었지만 해당문제에서는 `where`와 같이 다음 값을 다시 찾는 `continue`의 성격이 아닌 조건이 만족하는 순간 `for`문을 종료하고 값을 리턴 하도록 `if`를 사용하였다.

## 나의 풀이

### 첫번째 풀이
```swift
func solution(_ arr: [[Int]]) -> Int {

    for (i,v) in arr.enumerated() {
        for j in v.indices {
            if arr[i][j] != arr[j][i] {
                return 0
            }
        }
    }
    
    return 1
}
```

### 두번째 풀이
```swift
func solution(_ arr: [[Int]]) -> Int {

    for i in 0..<arr.count {
        for j in 0..<arr.count {
            if arr[i][j] != arr[j][i] {
                return 0
            }
        }
    }
    
    return 1
}
```

### 세번째 풀이
```swift
func solution(_ arr: [[Int]]) -> Int {
    for i in 0..<arr.count {
        for j in (i + 1)..<arr.count {
            if arr[i][j] != arr[j][i] {
                return 0
            }
        }
    }
    
    return 1
}
```
