# 피자 나눠 먹기 (3)

## 문제 설명
머쓱이네 피자가게는 피자를 두 조각에서 열 조각까지 원하는 조각 수로 잘라줍니다. 피자 조각 수 `slice`와 피자를 먹는 사람의 수 `n`이 매개변수로 주어질 때, `n`명의 사람이 최소 한 조각 이상 피자를 먹으려면 최소 몇 판의 피자를 시켜야 하는지를 return 하도록 solution 함수를 완성해보세요.

##제한사항
- 2 ≤ `slice` ≤ 10
- 1 ≤ `n` ≤ 100

## 입출력 예

| slice | n | result |
| :-- | :-- |
| 7 | 10 | 2 |
| 4 | 12 | 3 |

## 입출력 예 설명

입출력 예 #1
- 10명이 7조각으로 자른 피자를 한 조각 이상씩 먹으려면 최소 2판을 시켜야 합니다.

입출력 예 #2
- 12명이 4조각으로 자른 피자를 한 조각 이상씩 먹으려면 최소 3판을 시켜야 합니다.

## 배운점
- 정수 나눗셈 환경에서의 올림 공식 `(n + d - 1) / d`는 알고리즘 문제에서 **페이지네이션(Pagination) 처리**나 **버킷 분할** 할 때 매우 자주 쓰이는 테크닉 이라는것을 알게 되었다.
- 가독성 측면에서 수학적 올림 공식을 모르는 상황이 생길 수 있기 때문에 `while`문의 풀이가 가독성면에서는 좋지만 성능면으로 봤을때는 수학적 올림 공식을 사용하는 것이 `while`루프를 도는 것보다 좋다는 것을 알게 되었다.
- 또한 가독성과 성능의 타협점에는 변수를 선언하여 풀이하는 방법과 Swift 표준 라이브러리의 `ceil(Double(n) / Double(slice))`을 사용할 수 있다는 것도 알게 되었다.

## 나의 풀이

### 첫번째 풀이
```swift
func solution(_ slice:Int, _ n:Int) -> Int {
    
    var count = 1
    
    while (count * slice) < n {
        count += 1
    }
    
    return count
}
```

### 두번째 풀이
```swift
func solution(_ slice:Int, _ n:Int) -> Int {
    (n + (slice - 1)) / slice
}
```
