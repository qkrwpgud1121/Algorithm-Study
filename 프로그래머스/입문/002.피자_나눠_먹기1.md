# 피자 나눠 먹기 (1)

## 문제 설명
머쓱이네 피자가게는 피자를 일곱 조각으로 잘라 줍니다. 피자를 나눠먹을 사람의 수 `n`이 주어질 때, 모든 사람이 피자를 한 조각 이상 먹기 위해 필요한 피자의 수를 return 하는 solution 함수를 완성해보세요.

## 제한사항
- 1 ≤ `n` ≤ 100

## 입출력 예
| n | result |
| :-- | :-- |
| 7 | 1 |
| 1 | 1 |
| 15 | 3 |

## 입출력 예 설명

입출력 예 #1
- 7명이 최소 한 조각씩 먹기 위해서 최소 1판이 필요합니다.

입출력 예 #2
- 1명은 최소 한 조각을 먹기 위해 1판이 필요합니다.

입출력 예 #3
- 15명이 최소 한 조각씩 먹기 위해서 최소 3판이 필요합니다.

## 배운점
- Swift 에서는 정수의 연산은 나머지를 무조건 버린다는 것을 알게 되었다.
- 나누는 수보다 1작은 수를 분자에 미리 더해줌으로 나머지가 0일때는 종료, 나머지가 1이라도 존재할때는 강제로 다음 배수를 연산하게 하여 `ceil`의 사용 없이도 정수의 연산에 대한 올림을 할수 있다는것을 알게 되었다.
- 데이터의 크기에 비례하여 연산의 수가 늘어나는 `while`대신 한번의 연산 명령으로 처리하는 공식을 사용하여 성능면에서 매우 좋다는 것을 알게 되었다.
