# 중앙값 구하기

## 문제 설명
중앙값은 어떤 주어진 값들을 크기의 순서대로 정렬했을 때 가장 중앙에 위치하는 값을 의미합니다. 예를 들어 1, 2, 7, 10, 11의 중앙값은 7입니다. 정수 배열 `array`가 매개변수로 주어질 때, 중앙값을 return 하도록 solution 함수를 완성해보세요.

## 제한사항
`array`의 길이는 홀수입니다.
- 0 < `array`의 길이 < 100
- -1,000 < `array`의 원소 < 1,000

## 입출력 예

| array | result |
| :-- | :-- |
| [1, 2, 7, 10, 11] | 7 |
| [9, -1, 0] | 0 |

## 입출력 예 설명

입출력 예 #1
- 본문과 동일합니다.

입출력 예 #2
- 9, -1, 0을 오름차순 정렬하면 -1, 0, 9이고 가장 중앙에 위치하는 값은 0입니다.

## 배운점
- 문제의 제한 사항과 같이 데이터가 소규모 일때는 직관적인 `sorted()`를 사용하는 것이 생산성, 가독성, 유지보수 에서 최선이라는 것을 이해할 수 있었다.
- 하지만 데이터의 수가 수십억 개 단위로 커진다면 전체를 정렬할때 발생하는 오버헤드를 줄이기 위해 구역으로 나누어 필요한 인덱스만을 추적하는 `Quick Select` 알고리즘을 알게 되었다.
- 하여 알고리즘의 코드를 외우는것이 아닌 상황에 맞춰 오픈 소스를 활용해 내 상황에 맞춰 리펙토링하여 사용하는 감각을 알게 되었다.

- Swift에서는 함수의 전달인자 ( Argument Label, parameter)의 `Argument Label`을 `_`를 사용해 생략할 수 있다.

- Swift의 기본인 값의 복사에 대한 오버헤드를 차단하고 메모리에 저장되어 있는 원본 데이터를 직접 수정 하기위한 `inout`, `&`(앰퍼샌드) 를 사용한다는 것을 알게 되었다.
- 변수앞에 붙는 `&`기호는 함수 내부에서 원본 데이터가 직접 수정될 수 있다는 것을 컴파일러와 다른 개발자에게 시각적으로 보여주는 것이라는걸 알게되었다.
- 또한 생명주기의 제약으로 인해 `inout`은 무조건 함수의 파라미터 에서만 사용되어야 한다는것도 알게 되었다.


## 나의 풀이
```swift
func solution(_ array:[Int]) -> Int {
    array.sorted()[array.count / 2]
}
```

# Quick Select
```swift
func solution(_ array:[Int]) -> Int {
    
    var arr = array
    let targetIndex = arr.count / 2
    
    return quickSelect(&arr, 0, arr.count - 1, targetIndex)
}

func quickSelect(_ arr: inout [Int], _ left: Int, _ right: Int, _ k: Int) -> Int {
    
    if left == right { return arr[left] }
    
    let pivotIndex = partition(&arr, left, right)
    
    if k == pivotIndex {
        return arr[pivotIndex]
    } else if k < pivotIndex {
        return quickSelect(&arr, left, pivotIndex - 1, k)
    } else {
        return quickSelect(&arr, pivotIndex + 1, right, k)
    }
}

func partition(_ arr: inout [Int], _ left: Int, _ right: Int) -> Int {
    
    let mid = left + (right - left) / 2
    arr.swapAt(mid, right)
    
    let pivot = arr[right]
    var i = left
    
    for j in left..<right {
        if arr[j] < pivot {
            arr.swapAt(i, j)
            i += 1
        }
    }
    
    arr.swapAt(i, right)
    
    return i
}
```
