# 옷가게 할인 받기

## 문제 설명
머쓱이네 옷가게는 10만 원 이상 사면 5%, 30만 원 이상 사면 10%, 50만 원 이상 사면 20%를 할인해줍니다.
구매한 옷의 가격 `price`가 주어질 때, 지불해야 할 금액을 return 하도록 solution 함수를 완성해보세요.

## 제한사항
- 10 ≤ `price` ≤ 1,000,000
    - `price`는 10원 단위로(1의 자리가 0) 주어집니다.
- 소수점 이하를 버린 정수를 return합니다.

## 입출력 예
| price | result |
| :-- | :-- |
| 150,000 | 142,500 |
| 580,000 | 464,000 |

## 입출력 예 설명

입출력 예 #1
- 150,000원에서 5%를 할인한 142,500원을 return 합니다.

입출력 예 #2
- 580,000원에서 20%를 할인한 464,000원을 return 합니다.

## 배운점
- 첫번째 풀이의 `switch` 내부의 반복되는 계산식을 할인율만 추출하고 최종적으로 1번만 계산하도록 처리하여 코드의 중복을 제거 하였다.
- 금액의 범위를 100000..<300000 와 같이 닫힌 구간으로 만드는 것 보다 500000... 처럼 단방향의 범위를 설정하거나 세번째 풀이처럼 튜플배열을 사용하는 것이 조건이 추가되거나 변경되었을때 유지 보수에 훨씬 편하다는 것을 알게 되었다.

## 나의 풀이

### 첫번째 풀이
```swift
func solution(_ price:Int) -> Int {

    return switch price {
    case 100000..<300000:
        price - price * 5 / 100
    case 300000..<500000:
        price - price * 10 / 100
    default:
        price - price * 20 / 100
    }
}
```

### 두번째 풀이
```swift
func solution(_ price:Int) -> Int {

    var discountRate: Double
    
    switch price {
    case 500000...:
        discountRate = 0.20
    case 300000...:
        discountRate = 0.10
    case 100000...:
        discountRate = 0.05
    default:
        discountRate = 0.0
    }
    
    return Int(Double(price) * (1.0 - discountRate))
}
```

### 세번째 풀이
```swift
func solution(_ price:Int) -> Int {

    let discounts: [(range: Int, rate: Double)] = [
        (500000, 0.20),
        (300000, 0.10),
        (100000, 0.05)
    ]
    
    let rate = discounts.first(where: { price >= $0.range })?.rate ?? 0.0
    
    return Int(Double(price) * (1.0 - rate))
}
```
