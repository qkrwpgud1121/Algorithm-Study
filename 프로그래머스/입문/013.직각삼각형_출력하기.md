# 직각삼각형 출력하기

## 문제 설명
- "*"의 높이와 너비를 1이라고 했을 때, "*"을 이용해 직각 이등변 삼각형을 그리려고합니다. 정수 `n` 이 주어지면 높이와 너비가 `n` 인 직각 이등변 삼각형을 출력하도록 코드를 작성해보세요.

## 제한사항
- 1 ≤ `n` ≤ 10

## 입출력 예
입력 #1
```
3
```
출력 #1
```
*
**
***
```

## 입출력 예 설명

입출력 예 #1
- `n`이 3이므로 첫째 줄에 * 1개, 둘째 줄에 * 2개, 셋째 줄에 * 3개를 출력합니다.

## 배운점
- Swift 의 print의 뒤에는 항상 줄바꿈이 들어가 있기 때문에 줄바꿈을 하고 싶지 않다면 print의 옵션인 `terminator:`를 사용을 해주어야 한다.
- `forEach`와 `String(repeating:count:)`를 사용하여 반복문 없이도 문자를 지정된 횟수만큼 반복하여 나타낼수 있다.
- 매 줄 출력 후 해제하는 방식은 순간 최대의 메모리를 사용하지만, 하나의 변수에 전체를 누적하여 한번에 출력하는 방식은 계속하여 메모리를 유지하게 되어 메모리적으로는 좋지 않다.
- 아주 많은 양의 출력을 할때는 print의 횟수를 줄이는 방식이 속도 측면에서 유리 할 수 있다.

## 나의 풀이

### 첫번째 풀이
```swift
let n = readLine()!.components(separatedBy: [" "]).map { Int($0)! }

let roof = n.first ?? 0

for i in 1...roof {
    for _ in 1...i {
        print("*", terminator: "")
    }
    print("")
}
```

### 두번째 풀이
```swift
let n = readLine()!.components(separatedBy: [" "]).map { Int($0)! }

let roof = n.first ?? 0

(1...roof).forEach { print(String(repeating: "*", count: $0)) }
```
