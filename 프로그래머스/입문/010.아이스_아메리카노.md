# 아이스 아메리카노

## 문제 설명
머쓱이는 추운 날에도 아이스 아메리카노만 마십니다. 아이스 아메리카노는 한잔에 5,500원입니다. 머쓱이가 가지고 있는 돈 `money`가 매개변수로 주어질 때, 머쓱이가 최대로 마실 수 있는 아메리카노의 잔 수와 남는 돈을 순서대로 담은 배열을 return 하도록 solution 함수를 완성해보세요.

## 제한사항
- 0 < `money` ≤ 1,000,000

## 입출력 예
| money | result |
| :-- | :-- |
| 5,500 | [1, 0] |
| 15,000 | [2, 4000] |

## 입출력 예 설명

입출력 예 #1
- 5,500원은 아이스 아메리카노 한 잔을 살 수 있고 잔돈은 0원입니다.

입출력 예 #2
- 15,000원은 아이스 아메리카노 두 잔을 살 수 있고 잔돈은 4,000원입니다.

## 배운점
- 반복문을 사용해서 금액을 차감해 나가는 방식을 사용하지 않고 몫과 나머지를 구하는 연산을 사용하여 단 한번의 연산으로 처리하였다.
- 정해진 커피의 값을 변수로 선언하여 americanoPrice라는 변수명을 통해 의도를 명확히 하였으며 가격이 변동 되어도 변수의 값만 수정하면 되도록 하였다.
- `quotientAndRemainder(dividingBy:)` 라는 swift 표준 라이브러리 함수를 사용해 몫과 나머지를 각각의 연산이 아닌 하나의 연산을 통해 값을 구할수 있다는것을 알게 되었다.

## 나의 풀이

### 첫번째 풀이
```swift
func solution(_ money:Int) -> [Int] {
    let americanoPrice = 5500
    return [money / americanoPrice, money % americanoPrice]
}
```

### 두번째 풀이
```swift
func solution(_ money:Int) -> [Int] {
    let americanoPrice = 5500
    let (cups, change) = money.quotientAndRemainder(dividingBy: americanoPrice)
    return [cups, change]
}
```
