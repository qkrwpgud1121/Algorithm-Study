# 뒤집힌 문자열

## 문제 설명
- 문자열 `my_string`이 매개변수로 주어집니다. `my_string`을 거꾸로 뒤집은 문자열을 return하도록 solution 함수를 완성해주세요.

## 제한사항
- 1 ≤ `my_string`의 길이 ≤ 1,000

## 입출력 예
| my_string | return |
| :-- | :-- |
| "jaron" | "noraj" |
| "bread" | "daerb" |

## 입출력 예 설명

입출력 예 #1
- `my_string`이 "jaron"이므로 거꾸로 뒤집은 "noraj"를 return합니다.

입출력 예 #2
- `my_string`이 "bread"이므로 거꾸로 뒤집은 "daerb"를 return합니다.

## 배운점
- 이전 문제에서 사용했던 `reversed()`를 문자열에서도 사용할 수 있다.
- 만약 `reversed()`를 사용하지 않고 반복문을 사용한다면 **투포인터** 알고리즘을 사용할 수 있다.

### 투 포인터
| 유형 | 포인터 위치 및 이동 방식 | 주요 사용 상황 |
| 양 끝 탐색 (Cross/Opposite) | 포인터 L은 맨 앞(0), R은 맨 끝(N-1)에서 시작, 서로 중앙을 향해 반대 방향으로 이동 | 정렬된 배열에서 두 수의 합/차 구하기, 문자열/배열 뒤집기 |
| 같은 방향 탐색 (Sliding Window / Fast-Slow) | 두 포인터 L, R이 모두 맨 앞에서 출발, 조건에 따라 **같은 방향(오른쪽)**으로 이동 | 연속된 부분 수열의 합 구하기, 중복 문자가 없는 가장 긴 부분 문자열 구하기 |

### 투 포인터 풀이
```swift
func solution(_ my_string:String) -> String {
    var chars = Array(my_string)
    var left = 0
    var right = my_string.count - 1
    
    while left < right {
        chars.swapAt(left, right)
        left += 1
        right -= 1
    }
    
    return String(chars)
}
```

## 나의 풀이
```swift
func solution(_ my_string:String) -> String {
    String(my_string.reversed())
}
```
